# Noto web fonts

Original font families: Noto Sans and Noto Sans SC.
Source: Google Fonts CSS2 API; downloaded 2026-10-28.
CSS request: https://fonts.googleapis.com/css2?family=Noto+Sans:wght@100..900&family=Noto+Sans+SC:wght@100..900&display=swap

The unmodified WOFF2 subsets are served from this Site under /fonts/. The CSS preserves the provider unicode ranges and 100–900 variable weight range. Subsets are requested by browsers only when needed for displayed characters. The font stack prefers Apple system fonts before these web fonts.

Licenses: noto-sans-OFL.txt and noto-sans-sc-OFL.txt (SIL Open Font License 1.1). Source URLs and SHA-256 hashes for all subsets are in manifest.json.
